## 🚀 部署方式

### 方式一：自动部署脚本（推荐）
双击运行根目录下的 `DeployAutomationLib.bat` 脚本，自动完成编译和部署。

### 方式二：手动部署
1. 编译项目：
   ```bash
   dotnet build NodeLib.Automation/NodeLib.Automation.csproj --configuration Release
   ```

2. 复制文件到节点库目录：
   ```bash
   cp NodeLib.Automation/bin/Release/net8.0-windows/* %USERPROFILE%/Documents/XNode/NodeLib/
   ```

## 🎮 使用方法

### 1. 启动 XNode
重启 XNode 应用程序，节点库会在启动时自动加载。

### 2. 查找节点
在节点库面板中，您会看到新增的"自动化"分类，包含以下子分类：
- **输入操作** - 鼠标点击、鼠标移动
- **视觉识别** - 屏幕截图、查找图像
- **流程控制** - 延迟

### 3. 使用示例

#### 示例 A：自动点击指定位置
```
[开始] → [鼠标移动(X:500, Y:300)] → [延迟(500ms)] → [鼠标点击(左键)]
```

#### 示例 B：查找图像并点击
```
[开始] → [屏幕截图(全屏)] → [查找图像(模板)]
           ↓                      ↓
        截图路径  ──────────→  源图像
                              ↓
                        [是否找到?]
                              ↓
                        [鼠标点击]
                         (连接X、Y坐标)
```

## 🔧 节点详细说明

### 鼠标点击节点
- **输入**: X坐标、Y坐标、按钮类型("左键"/"右键"/"中键")
- **功能**: 移动鼠标并执行点击

### 鼠标移动节点
- **输入**: X坐标、Y坐标
- **功能**: 仅移动鼠标，不点击

### 屏幕截图节点
- **输入**: X、Y、宽度、高度、保存路径(可选)
- **输出**: 截图文件路径
- **说明**: 留空保存路径会自动保存到临时目录

### 查找图像节点（OpenCV）
- **输入**: 源图像路径、模板图像路径、匹配阈值(0.0-1.0)
- **输出**: 是否找到、X坐标、Y坐标、匹配度
- **说明**:
  - 使用 OpenCV 模板匹配算法
  - 返回匹配图像的中心点坐标
  - 阈值建议设置为 0.7-0.9

### 延迟节点
- **输入**: 延迟时间(毫秒)
- **功能**: 暂停执行流程

## ⚠️ 注意事项

1. **坐标系统**: 使用屏幕绝对坐标，左上角为 (0, 0)
2. **权限限制**: 某些应用程序（如游戏、系统工具）可能阻止模拟输入
3. **性能考虑**: 图像识别操作耗时较长，建议合理设置延迟
4. **模板图像要求**:
   - 推荐使用 PNG 格式
   - 模板不能大于源图像
   - 确保模板图像与目标相似度高

## 🛠️ 技术栈

- **OpenCvSharp4** - 计算机视觉和图像识别
- **System.Windows.Forms** - 鼠标/键盘控制

## 🐛 故障排除

### 问题：XNode 启动后看不到"自动化"节点库
**解决方案**:
1. 确认文件已复制到正确位置：`%USERPROFILE%\Documents\XNode\NodeLib\`
2. 确认 `NodeLib.Automation.dll` 文件存在
3. 查看 XNode 日志是否有加载错误

### 问题：鼠标点击无效
**解决方案**:
1. 确认目标应用程序未阻止模拟输入
2. 尝试使用管理员权限运行 XNode
3. 检查坐标是否正确

### 问题：图像查找始终返回"未找到"
**解决方案**:
1. 降低匹配阈值（如从 0.8 降到 0.7）
2. 确保模板图像与目标区域完全一致
3. 使用屏幕截图节点先截取目标区域作为模板
