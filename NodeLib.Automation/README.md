# NodeLib.Automation - XNode 自动化节点库

这是一个为 XNode 开发的自动化节点库，提供了鼠标控制、屏幕截图和图像识别等自动化功能。

## 功能特性

### 🖱️ 输入操作节点
- **鼠标点击** - 在指定坐标执行鼠标点击(支持左键/右键/中键)
- **鼠标移动** - 移动鼠标到指定坐标

### 👁️ 视觉识别节点
- **屏幕截图** - 捕获屏幕指定区域并保存为图片
- **查找图像** - 使用 OpenCV 模板匹配在屏幕上查找指定图像

### ⏱️ 流程控制节点
- **延迟** - 暂停执行指定的毫秒数

## 技术栈

- **.NET 8.0** - 基础框架
- **OpenCvSharp4** - 图像识别和计算机视觉
- **System.Windows.Forms** - 鼠标和键盘控制
- **XLib.Node** - XNode 节点系统基础库

## 编译项目

```bash
dotnet build NodeLib.Automation/NodeLib.Automation.csproj
```

Release 版本:
```bash
dotnet build NodeLib.Automation/NodeLib.Automation.csproj --configuration Release
```

## 安装和使用

1. 编译项目生成 DLL 文件
2. 将编译输出目录中的所有文件复制到:
   ```
   %USERPROFILE%\Documents\XNode\NodeLib\
   ```
3. 重启 XNode 应用程序,节点库将自动加载

## 节点说明

### 鼠标点击节点

**输入引脚:**
- X坐标 (int) - 点击位置的 X 坐标
- Y坐标 (int) - 点击位置的 Y 坐标
- 按钮 (string) - 点击按钮类型: "左键"/"右键"/"中键"

### 鼠标移动节点

**输入引脚:**
- X坐标 (int) - 目标位置的 X 坐标
- Y坐标 (int) - 目标位置的 Y 坐标

### 屏幕截图节点

**输入引脚:**
- X坐标 (int) - 截图区域左上角 X 坐标
- Y坐标 (int) - 截图区域左上角 Y 坐标
- 宽度 (int) - 截图区域宽度
- 高度 (int) - 截图区域高度
- 保存路径 (string) - 可选,留空则保存到临时目录

**输出引脚:**
- 截图 (string) - 截图文件的完整路径

### 查找图像节点

使用 OpenCV 的模板匹配算法在源图像中查找目标图像。

**输入引脚:**
- 源图像 (string) - 源图像文件路径(通常是屏幕截图)
- 模板图像 (string) - 要查找的模板图像文件路径
- 阈值 (double) - 匹配阈值 (0.0-1.0),默认 0.8

**输出引脚:**
- 找到 (bool) - 是否找到匹配
- X坐标 (int) - 找到的图像中心点 X 坐标
- Y坐标 (int) - 找到的图像中心点 Y 坐标
- 匹配度 (double) - 匹配相似度 (0.0-1.0)

### 延迟节点

**输入引脚:**
- 延迟(毫秒) (int) - 延迟时间,单位为毫秒

## 使用示例

### 示例 1: 点击屏幕指定位置

1. 添加"鼠标点击"节点
2. 设置 X坐标 = 500, Y坐标 = 300
3. 设置 按钮 = "左键"
4. 连接执行流

### 示例 2: 查找并点击图像

1. 添加"屏幕截图"节点,截取全屏
2. 添加"查找图像"节点,设置模板图像路径
3. 将截图节点的"截图"输出连接到查找图像的"源图像"输入
4. 添加"鼠标点击"节点
5. 将查找图像的"X坐标"和"Y坐标"连接到鼠标点击节点
6. 添加"延迟"节点,设置适当的延迟时间

## 注意事项

1. **坐标系统**: 使用屏幕绝对坐标,左上角为 (0, 0)
2. **权限要求**: 某些应用程序可能会阻止模拟输入
3. **性能考虑**: 图像识别操作较耗时,建议合理设置延迟
4. **模板图像**:
   - 建议使用 PNG 格式
   - 模板图像不能大于源图像
   - 阈值越高匹配越严格,建议值 0.7-0.9

## 开发参考

本项目参考了 `NodeLib.File` 的实现结构。如需开发新节点:

1. 继承 `NodeBase` 类
2. 实现必要的方法:
   - `Init()` - 初始化引脚和属性
   - `ExecuteNode()` - 节点执行逻辑
   - `GetTypeString()` - 返回节点类型名
   - `GetParaDict()` / `LoadParaDict()` - 参数序列化
   - `CloneNode()` - 节点克隆

3. 在 `AutomationLib.cs` 中注册新节点
